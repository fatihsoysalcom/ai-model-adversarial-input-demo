# AI Model Adversarial Input Demo

This example demonstrates a simplified adversarial attack on a basic AI model (a perceptron). It shows how a small, seemingly insignificant perturbation to input data can cause a trained model to misclassify. This highlights a fundamental challenge in AI security, where models are vulnerable to subtle data manipulations beyond traditional cybersecurity threats.

## Language

`python`

## How to Run

Save the code as `main.py`. Run from your terminal: `python main.py`
